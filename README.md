This was a snake game I made for a University assignment.

This game doesn't entirely function as intended, and I never had the time to fix it.

About the game:
It's a standard game of snake, however the snake must stay underwater. Every so often the snake must rise for air. If the snake goes too far above the water however, the snake will take damage, and same if it stays underwater for too long.

Bugs:
The AI snake forgets it needs air, and doesn't rise, thus ending the game early.
The health and air bars go off-screen, making it hard to comprehend how much time you have.
